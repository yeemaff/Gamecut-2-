# 🎮 GameCut 2 — คัดช็อตเด็ดจากฟุตเทจเกม

โยนฟุตเทจเกมยาวๆ เข้าไป (เช่น 1 ชั่วโมง) → ได้คลิปไฮไลต์ 1–2 นาที + ไฟล์แยกทุกช็อต เป็นไฟล์วิดีโอธรรมดา (MP4) ลากเข้า Premiere Pro ได้เลย
รันบนเครื่องของคุณเอง ทั้ง **Mac และ Windows PC** ไม่ต้องอัปโหลดฟุตเทจไปไหน

## แอพหาช็อตเด็ดยังไง

| สัญญาณ | หาอะไร |
|---|---|
| 🎬 ความเคลื่อนไหวของภาพ | ฉากต่อสู้ แอคชั่น กล้องหมุนเร็ว |
| 🔊 ความดังเสียงเกม | ช่วงที่ดังขึ้นกะทันหัน — ระเบิด ตีบอส คอมโบ (ใช้แค่วิเคราะห์ ไฟล์ที่ได้ไม่มีเสียง เว้นแต่เปิดไว้) |
| 🚫 ข้ามอัตโนมัติ | จอโหลด เมนู pause ภาพค้าง (ฉากมืดที่ยังเคลื่อนไหว เช่น ถ้ำ/กลางคืน จะไม่ถูกข้าม) |
| 📏 กระจายช็อต | เกลี่ยให้ทั่วไฟล์ — ฉากที่มันส์มากได้หลายช็อต แต่ไม่กองอยู่ที่เดียว |

ฟุตเทจ 1 ชั่วโมงสแกนประมาณ 1–5 นาที (ขึ้นกับเครื่องและความละเอียดไฟล์) และสแกนครั้งเดียว — เปลี่ยนตั้งค่าแล้วคัดใหม่ได้ทันที

## ✨ ฟีเจอร์

1. **ทำให้ภาพชัดขึ้น** (ขั้นที่ 3) — สำหรับฟุตเทจคุณภาพต่ำ
   - **เบา**: ลด noise + เพิ่มความคม (ฟุตเทจที่ดีอยู่แล้ว)
   - **กลาง**: ลบรอยบล็อกจากการบีบอัด + ลด noise + คมขึ้น + สีสดขึ้นนิด (ไฟล์บิตเรตต่ำ / โหลดจากเว็บ) ← แนะนำ
   - **แรง**: เต็มที่ + ลบแถบสี (ฟุตเทจเก่า / ไฟล์เล็ก — ช้ากว่า)
   - **ขยายความละเอียด** เป็น 1080p / 1440p / 4K (ขยายเฉพาะไฟล์ที่เล็กกว่า)
   - กด **🔍 ดูภาพเทียบ ก่อน / หลัง** — ซูม 100% บริเวณเดียวกัน ให้เห็นความต่างจริงก่อนส่งออก
2. **กราฟความมันส์ทั้งไฟล์** — เห็นว่าช่วงไหนมันส์ ช็อตที่เลือกเป็นแถบสีเขียว
   - **คลิกที่กราฟ** → ดูวิดีโอช่วงนั้น → กด "➕ เพิ่มช่วงนี้เป็นช็อต"
   - ทุกช็อต: ▶ ดู · **↻ สลับ** (เปลี่ยนเป็นช็อตที่มันส์รองลงมา) · −1s/+1s · ✕ ลบ
   - **▶ ดูไฮไลต์ทั้งหมดต่อกัน** ก่อนส่งออก
3. **Reel / Shorts 9:16 และสี่เหลี่ยม 1:1** (ขั้นที่ 4) — ครอปเต็มจอ / พื้นหลังเบลอ / ขอบดำ
4. **หลายไฟล์ทีเดียว** — ใส่ทั้งโฟลเดอร์ (เรียงตามเลขชื่อไฟล์ 1, 2, 3…) แต่ละไฟล์ได้ไฮไลต์ของตัวเอง + คลิปรวมทุกไฟล์

## ผลลัพธ์

```
GameCut_Highlights/
└── Highlights_20261030-2006/            (Reel จะลงท้าย _reel)
    ├── 01_EP12-gameplay/
    │   ├── EP12-gameplay_highlight.mp4  ← คลิปไฮไลต์รวม
    │   ├── shots/
    │   │   ├── 01_02m40s_6.0s.mp4       ← แยกทุกช็อต (ชื่อ = เวลาในฟุตเทจต้นฉบับ)
    │   │   └── …
    │   └── shots.csv                    ← รายการช็อต + เวลา
    ├── 02_EP13-gameplay/ …
    └── ALL_highlights.mp4               ← รวมไฮไลต์ทุกไฟล์
```

- **MP4 (H.264)** ใช้การ์ดจอเข้ารหัสอัตโนมัติ (Mac: VideoToolbox · PC: NVIDIA/Intel/AMD)
- **MOV (ProRes)** ไฟล์ใหญ่ แต่ลื่นกว่าตอนตัดต่อใน Premiere
- ค่าเริ่มต้น **ภาพอย่างเดียว ไม่มีเสียงเกม** (เปิดได้ที่ขั้นที่ 5)

## 🍎 Mac

ติดตั้งครั้งเดียวใน Terminal: `brew install ffmpeg python@3.12` (ถ้ายังไม่มี Homebrew ดู https://brew.sh)
แล้ว **ดับเบิลคลิก `start.command`** — หน้าแอพจะเปิดในเบราว์เซอร์เอง (เปิดหน้าต่าง Terminal ค้างไว้ระหว่างใช้)

> ถ้า Mac บล็อก: คลิกขวาที่ `start.command` → Open → Open (หรือ System Settings → Privacy & Security → Open Anyway)

## 🪟 Windows

แตก zip (คลิกขวา → Extract All) แล้ว **ดับเบิลคลิก `start.bat`**
- ถ้ายังไม่มี Python จะถามว่าจะติดตั้งไหม → กด **Y** แล้วเปิด `start.bat` อีกครั้ง
- ครั้งแรกแอพจะ **ดาวน์โหลด ffmpeg ให้เอง** (~90 MB)

> ถ้าขึ้น "Windows protected your PC": More info → Run anyway

**ใช้ SSD ลูกเดียวสลับ Mac ↔ PC ได้** (ฟอร์แมต exFAT) — แต่ละเครื่องมีไลบรารีแยกกันใน `.venv` / `.venv-win`

## อัปเดตจากเวอร์ชันเก่า

วางไฟล์ใหม่ทับในโฟลเดอร์ GameCut เดิม (กด Apply to All → Replace) แอพจะติดตั้งไลบรารีที่ต้องใช้เพิ่มให้เอง
โฟลเดอร์ `models` ของเวอร์ชันเก่า (โมเดลถอดเสียง) ไม่ใช้แล้ว ลบทิ้งได้เพื่อคืนพื้นที่ ~0.5–1.5 GB

## เคล็ดลับ

- **ได้ช็อตเรียบๆ มาเยอะ?** ลดความยาวไฮไลต์ หรือตั้ง "กระจายช็อต" เป็น **น้อย** (เอาเฉพาะฉากที่มันส์สุด)
- **ช็อตกองอยู่ฉากเดียว?** ตั้ง "กระจายช็อต" เป็น **มาก**
- **ช่วงเริ่มอัดมีหน้า OBS / หน้าจอเดสก์ท็อป?** ใช้ "ข้ามช่วงต้น/ท้ายไฟล์"
- **ส่งออกช้า?** โหมดทำให้ชัด "แรง" ใช้ CPU หนัก — ลองโหมด "กลาง" ก่อน หรือปิดถ้าฟุตเทจคมชัดอยู่แล้ว
- **ดูตัวอย่างไฟล์ .mkv ในแอพไม่ได้** — เบราว์เซอร์เล่น mkv ไม่ได้ แต่สแกน/ตัด/ส่งออกได้ปกติ
